# العدد والمعدات حسب النشاط

احسب العدد = عدد الفرق المتوازية في النشاط × الكمية لكل فريق، + 10–20% احتياطي للأدوات المعرضة للتلف أو الفقد.

## عدة يدوية شخصية (لكل فني)
شنطة عدة: مفكات معزولة VDE، زرادية، قطاعة، مقشرة أسلاك، شريط قياس، ميزان ماء، مفتاح فحص (Voltage tester)، كشاف رأس.
**لكل مساعد:** شريط قياس، زرادية، قطاعة، مفكات.

## حسب النشاط
| النشاط | العدد والمعدات (لكل فريق) |
|---|---|
| مواسير PVC | منشار مواسير، سوستة ثني (Bending spring)، لاصق، مثقاب (Hammer drill) |
| مواسير GI/EMT | ماكينة ثني مواسير (Bender) يدوي/هيدروليك، ماكينة قلوظة (Threading)، منشار حديد |
| Cable tray | صاروخ قص (Grinder)، دريل SDS + لقم، مفتاح عزم، سلم/سقالة، Rod cutter لقضبان التعليق |
| سحب الأسلاك | سلك سحب (Fish tape) 30 م، شحم سحب |
| سحب كيبلات كبيرة | حامل بكرات (Drum jacks)، بكرات أرضية وزاوية (Cable rollers)، ونش سحب (Cable winch) مع جورب سحب (Pulling sock)، أجهزة لاسلكي |
| توصيل الكيبلات | قطاعة كيبلات (Ratchet cable cutter)، كبّاسة هيدروليك (Crimping tool) مع Dies حتى 300 مم²، مقشرة كيبلات مسلحة، مفتاح عزم (Torque wrench)، Heat gun |
| نهايات MV | عدة نهايات MV كاملة، Heat gun/موقد غاز، مقشرة Semi-con |
| لوحات | مفتاح عزم، طقم لقم، Forklift/رافعة شوكية أو Pallet jack، Crowbar ولوح انزلاق |
| لوحات تحكم | مقشرة أوتوماتيكية، كبّاسة Ferrule/Lugs صغيرة، طابعة أرقام (Ferrule printer)، مفكات صغيرة |
| إنارة وأجهزة | سلالم (2–3 م)، دريل لاسلكي، منشار ثقوب (Hole saw) للأسقف المستعارة |
| إنارة عالية/خارجية | سقالة متحركة أو رافعة أشخاص (Scissor/Boom lift) |
| تأريض | مطرقة قضبان/Driver، قالب لحام Exothermic (Cadweld) |
| محولات ومعدات ثقيلة | رافعة (Mobile crane) حسب الوزن + Lift plan، أحزمة وشكالات معتمدة |
| PV | دريل/مفكات عزم، كبّاسة MC4، مفتاح MC4 |

## السلامة (لكل عامل)
خوذة، حذاء سلامة، نظارات، قفازات عمل، سترة عاكسة، قفازات عزل كهربائي (Class حسب الجهد) للعاملين على اللوحات، حزام أمان للعمل على ارتفاع > 1.8 م، أقفال وبطاقات LOTO (طقم لكل فريق لوحات)، طفاية CO₂ قرب اللوحات.

## معدات الموقع العامة
لوحات توزيع مؤقتة مع RCD، كيبلات تمديد صناعية، إضاءة مؤقتة، مولد مؤقت إن لزم، كونتينر مخزن، رفوف، حامل بكرات في المخزن.
