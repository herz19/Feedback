# طريقة العمل وتسلسل التنفيذ (Method Statements)

لكل نظام: المتطلبات قبل البدء ← الخطوات ← نقاط الاستلام (Hold Points) ← السلامة.
قبل أي نشاط: مخططات معتمدة (IFC/Shop drawings)، مواد معتمدة (Material Submittal Approved)، تصريح عمل (PTW)، اجتماع سلامة (Toolbox talk).

## 0. أعمال التحضير (كل المشاريع)
1. استلام الموقع ومراجعة المخططات وتجهيز Shop drawings.
2. تقديم اعتمادات المواد (Submittals) وطلب البنود طويلة التوريد فوراً (محولات، MDB، مولدات، MCC، لوحات تحكم): 8–20 أسبوع غالباً.
3. تجهيز المخزن والمكتب والكهرباء المؤقتة ولوحات الموقع المؤقتة مع RCD.
4. خطة الجودة (ITP) وخطة السلامة.

## 1. تمديدات المباني
| المرحلة | النشاط | يتبع | Hold point |
|---|---|---|---|
| هيكل | مواسير وعلب في الأسقف قبل الصب (Slab conduits) | تسليح السقف | فحص قبل الصب مع الاستشاري |
| هيكل | تأريض الأساسات (Foundation earthing) | الحفر | قياس قبل الردم |
| تشطيب أولي | مواسير الجدران والعلب بعد البلوك وقبل اللياسة | البلوك | فحص قبل اللياسة |
| تشطيب أولي | Cable tray/trunking والحوامل | الأسقف الخرسانية | فحص المسارات والتثبيت |
| تشطيب أولي | تركيب اللوحات الفارغة (Enclosures) | اللياسة | — |
| سحب | سحب الأسلاك والكيبلات | المواسير + اللياسة | فحص العزل قبل التوصيل |
| تشطيب نهائي | الأجهزة (مفاتيح، أفياش) ووحدات الإنارة | الدهان والأسقف المستعارة | — |
| تشطيب نهائي | توصيل اللوحات (Dressing) والقواطع | السحب | — |
| فحص | عزل، استمرارية، قطبية، RCD، مقاومة الأرض | التوصيل | استلام مع الاستشاري |
| تشغيل | تغذية مؤقتة ← دائمة، اختبار الأحمال | ربط SEC | محضر استلام |

## 2. لوحات التوزيع و MCC
1. استلام اللوحة في المصنع (FAT) إن أمكن: فحص الأبعاد، القواطع، Torque، IR، Hi-pot.
2. التحضير: قاعدة/Plinth أو Channel base، فتحات الكيبلات، فحص المستوى.
3. النقل والرفع: رافعة/Forklift حسب الوزن، أحزمة رفع، منطقة معزولة.
4. التثبيت والتسوية وتوصيل الخلايا ببعض (Busbar links) بعزم الربط حسب المصنع.
5. سحب الكيبلات ← الـ Glands ← الـ Lugs (Crimping) ← التوصيل ← Torque marking.
6. للـ MCC: توصيل المحركات، أسلاك التحكم، فحص اتجاه الدوران.
7. الفحص: IR، Torque، Phase sequence، تشغيل الحمايات (Secondary injection للـ ACB/relays).
8. التشغيل بالتدريج: بدون حمل ← حمل جزئي ← حمل كامل، قياس التيارات وحرارة التوصيلات (Thermal imaging).
- **السلامة:** LOTO إلزامي، لا عمل على لوحة مكهربة.

## 3. لوحات التحكم و PLC
1. مراجعة الـ I/O list والـ Control philosophy مع المالك.
2. تصميم المخططات (Schematic, Layout, Terminal) واعتمادها.
3. التصنيع: تركيب الـ DIN rails والـ Ducts ← الأجهزة ← الأسلاك ← الترقيم (Ferrules).
4. فحص في الورشة (FAT): Point-to-point، IR، محاكاة I/O، تشغيل البرنامج.
5. الموقع: تركيب، سحب كيبلات التحكم والأجهزة، توصيل الأجهزة الميدانية.
6. Loop check لكل نقطة I/O ← Cold commissioning ← Hot commissioning ← SAT ← التدريب والتسليم مع نسخ البرامج.

## 4. محطات ومشاريع الطاقة
### محطة تحويل (RMU + محول + LV)
1. الأعمال المدنية: غرفة/قاعدة، خنادق الكيبلات، نظام التأريض (شبكة + قضبان) مع القياس.
2. وصول المحول وفحصه (زيت، ملحقات)، الوضع برافعة مع خطة رفع (Lift plan).
3. RMU والتثبيت، كيبلات MV ونهاياتها (فني معتمد لنهايات MV).
4. فحوصات: IR، VLF/Hi-pot لكيبلات MV، نسبة التحويل (TTR)، مقاومة الملفات، الحمايات.
5. تنسيق مع SEC للربط والعداد واستلام المحطة حسب متطلباتها.

### مولد + ATS
قاعدة مضادة للاهتزاز ← وضع المولد ← العادم والوقود ← كيبلات الطاقة والتحكم ← اختبار حمل (Load bank) ← اختبار التحويل التلقائي.

### طاقة شمسية
مسح الموقع والأسقف ← تثبيت الهياكل ← الألواح ← Strings وكيبلات DC ← Combiner/Inverters ← AC ← الفحص (Voc، Isc، IR، القطبية) ← الربط مع الشبكة حسب اشتراطات SEC/هيئة تنظيم الكهرباء ← المراقبة.

## نقاط عامة لكل Method Statement يُكتب
- النطاق، المراجع، المسؤوليات (مدير مشروع، مهندس موقع، مشرف، HSE، QC).
- المعدات والعدد (من tools-equipment.md).
- الخطوات بالتسلسل.
- تحليل المخاطر (JSA): الصعق، السقوط، الرفع، الحرارة.
- نماذج الفحص (ITP checklists).
