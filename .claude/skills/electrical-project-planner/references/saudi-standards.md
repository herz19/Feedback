# مراجع ومتطلبات نظامية (السعودية)

> تحقق دائماً من الإصدار الساري ومتطلبات العقد؛ هذه قائمة للتذكير وليست نصوص الأنظمة.

| المرجع | المجال |
|---|---|
| **كود البناء السعودي SBC 401** (المتطلبات الكهربائية) | تمديدات المباني، الحماية، التأريض |
| **SBC 801** (الحماية من الحريق) ومتطلبات الدفاع المدني | إنذار الحريق، إنارة الطوارئ |
| **اشتراطات الشركة السعودية للكهرباء (SEC)** ومواصفاتها للتوزيع | الربط بالشبكة، المحطات، العدادات، غرف المحولات |
| **الهيئة السعودية للمواصفات SASO** | مطابقة المواد والأجهزة (شهادات المطابقة) |
| **هيئة تنظيم الكهرباء (ECRA سابقاً، الهيئة حالياً)** | تنظيم الأنشطة، الطاقة الشمسية الموزعة الصغيرة |
| **IEC 60364** | التمديدات منخفضة الجهد (مرجع أساسي لـ SBC 401) |
| **IEC 61439** | لوحات التوزيع و MCC |
| **IEC 61131-3** | برمجة PLC |
| **IEC 62446 / IEC 62548** | أنظمة PV: التصميم والفحص |
| **NFPA 70E** | سلامة العمل الكهربائي (يعتمده كثير من المالكين والاستشاريين) |
| مواصفات Aramco (SAES/SAMSS) | مشاريع أرامكو وما يتبعها – تختلف عن المشاريع العامة |
| نظام العمل السعودي | ساعات العمل، رمضان، العمل الإضافي، حظر العمل وقت الظهيرة صيفاً |
| الهيئة السعودية للمهندسين | تسجيل المهندسين |

## جهود الشبكة الشائعة
- توزيع متوسط: 13.8 kV (وأيضاً 33 kV و 11 kV في بعض المناطق).
- منخفض: 400/230 V (المعيار الحالي) وقد تجد 380/220 V في منشآت قديمة؛ 60 Hz.

## ضريبة القيمة المضافة
15% على التوريد والتنفيذ؛ اعرض الأسعار قبل وبعد الضريبة.
