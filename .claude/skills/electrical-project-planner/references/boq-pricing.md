# التسعير و BOQ (السعودية – ريال)

## مصدر الأسعار
- المصدر الوحيد: `templates/price-list.csv` أو عروض الموردين التي يرسلها المستخدم.
- كل سعر يحمل: المورد، تاريخ العرض، شامل/غير شامل VAT، شامل التوريد للموقع أم لا.
- عرض أقدم من 90 يوماً للنحاس والكيبلات: نبّه أن السعر قد تغيّر (النحاس متقلب).
- البند بدون سعر: `TBD` في جدول منفصل "بنود تحتاج تسعير" مع المواصفات المطلوبة لطلب عرض سعر.

## تركيب سعر البند (Unit Rate Build-up)

```
سعر الوحدة = مواد + عمالة + معدات + مستهلكات
  مواد      = سعر المورد × (1 + هدر) + نقل
  عمالة     = ساعات عمل للوحدة × تكلفة ساعة العامل المحمّلة
  معدات     = حصة البند من إيجار المعدات (رافعة، سقالات، ونش سحب كيبل)
  مستهلكات  = 3–5% من المواد (شريط، رباطات، براغي، Lugs صغيرة) إن لم تُحسب منفصلة

الإجمالي = Σ(كمية × سعر الوحدة)
         + مصاريف موقع (Site overheads)   ← 8–12% (مكتب، سكن، نقل عمال، كهرباء ومياه مؤقتة)
         + مصاريف عامة (Head office)     ← 3–6%
         + احتياطي مخاطر (Contingency)   ← 2–5% حسب وضوح المخططات
         + ربح                            ← حسب قرار المستخدم (لا تفترضه؛ اسأل)
         + VAT 15%
```
النسب أعلاه قيم بداية شائعة للنقاش وليست قاعدة؛ اعرضها كمتغيرات يغيّرها المستخدم.

## نسب الهدر الشائعة
| المادة | الهدر |
|---|---|
| أسلاك ودوائر فرعية | 5–8% |
| كيبلات رئيسية (Feeders) | 3–5% + أطوال الأطراف |
| مواسير PVC/GI | 5–10% |
| Cable tray/ladder | 3–5% |
| إكسسوارات صغيرة | 5% |

## تكلفة العامل المحمّلة (Loaded labour cost)
اطلب من المستخدم الأرقام الفعلية. التركيب:
راتب + بدل سكن + نقل + إقامة ورخصة عمل + تأمين طبي + GOSI + تذاكر وإجازات ونهاية خدمة ÷ ساعات العمل الفعلية في الشهر (≈ 208 ساعة، أقل في رمضان).

## مطابقة BOQ المالك
1. طابق كل بند بالكود والوصف.
2. اعرض: بنود ناقصة في BOQ المالك، كميات فرقها > 5%، بنود وصفها مبهم (يحتاج استيضاح RFI).
3. لا تغيّر كميات المالك في ملف التسعير الرسمي؛ ضع الفروق في ورقة منفصلة "ملاحظات العطاء".

## مخرجات التسعير (Excel)
- ورقة BOQ: البند، الوصف، الوحدة، الكمية، مواد/وحدة، عمالة/وحدة، سعر الوحدة، الإجمالي، المصدر.
- ورقة ملخص حسب القسم (لوحات، كيبلات، إنارة، أفياش، تأريض، أنظمة خفيفة، تشغيل وفحص).
- ورقة بنود تحتاج تسعير، ورقة الافتراضات، ورقة الاستثناءات (Exclusions).
- استخدم معادلات Excel لا أرقام ثابتة، حتى يغيّر المستخدم النسب.
