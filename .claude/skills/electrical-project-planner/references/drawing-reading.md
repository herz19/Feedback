# قراءة المخططات الكهربائية واستخراج الكميات

## ترتيب القراءة
1. **جدول المخططات (Drawing List) والملاحظات العامة (General Notes)**: المواصفات، نوع الكيبلات، طريقة التمديد، الارتفاعات.
2. **الرموز (Legend)**: لا تفترض معنى رمز غير موجود في الـ Legend. اسأل.
3. **المخطط الأحادي (SLD)**: مصدر التغذية ← المحول ← MDB ← SMDB ← DB. منه تستخرج: اللوحات، القواطع الرئيسية، الكيبلات الرئيسية (Feeders).
4. **جداول اللوحات (Panel/DB Schedules)**: عدد الدوائر، القواطع (النوع، التيار، عدد الأقطاب، kA)، مقطع الكيبل لكل دائرة.
5. **مخططات التوزيع (Layouts)**: إنارة، قوى (أفياش)، أنظمة خفيفة، مسارات الحوامل.
6. **التفاصيل (Details)**: التأريض، تركيب اللوحات، مقاطع الحوامل.

## ما يُستخرج من كل نوع مخطط

| المخطط | الكميات |
|---|---|
| SLD | محولات، RMU، مولد، ATS، MDB/SMDB/DB، MCC، مكثفات (Capacitor bank)، كيبلات الـ Feeders (المقطع، عدد الأقطاب، النوع XLPE/PVC، Armoured) |
| Panel schedule | قواطع MCB/MCCB/ACB حسب التيار والأقطاب، RCD/RCBO، عدادات، SPD، عدد الـ Ways |
| Lighting layout | وحدات إنارة حسب النوع، مفاتيح، حساسات، إنارة طوارئ، Exit، مواسير وأسلاك الإنارة |
| Power layout | أفياش 13A، أفياش صناعية، Isolators، نقاط تغذية للأجهزة (AC، سخانات، مضخات) |
| Cable routing | Cable tray/ladder/trunking بالعرض، الأكواع والتقاطعات، الحوامل (Supports) |
| Earthing | قضبان، حفر تفتيش، شريط/كيبل نحاس، Earth bars، التوصيلات |
| Control/PLC | عدد I/O (DI/DO/AI/AO)، Terminals، Relays، Contactors، VFD/Soft starters، HMI، كيبلات Control/Instrument |
| PV layout | عدد الألواح، Strings، Inverters، Combiner boxes، كيبلات DC/AC، هياكل التثبيت |

## طرق الحصر

- **العد (Count)**: الرموز (وحدات الإنارة، الأفياش...). عدّ لكل طابق ولكل لوحة واذكرها.
- **الأطوال**: طول المسار على المخطط × مقياس الرسم + الارتفاع العمودي (من السقف إلى الجهاز ومن اللوحة إلى السقف) + 
  - **للكيبلات الرئيسية**: + 1.5 إلى 3 م لكل طرف (Termination loop) + نسبة هدر.
  - **إذا لم يُرسم المسار**: طول مستقيم بين النقطتين × 1.25 (معامل التعرج) واذكر ذلك كافتراض.
- **الدوائر الفرعية بدون مسار**: متوسط طول الدائرة × عدد الدوائر (مثال افتراضي شائع: إنارة 15–25 م، أفياش 20–30 م) ويُذكر كافتراض.

## ملفات CAD
- PDF/صور: اقرأها مباشرة. إذا الدقة ضعيفة اطلب نسخة أوضح أو DWG.
- DWG/DXF: استخدم Python مع `ezdxf` (DXF مباشرة؛ DWG يحتاج تحويل بـ ODA File Converter) لعدّ البلوكات (Block references) حسب الاسم والطبقة، وجمع أطوال الخطوط في طبقات المسارات. طابق أسماء البلوكات مع الـ Legend قبل اعتماد العدد.

## علامات التحذير (اذكرها للمستخدم)
- تعارض بين SLD وجدول اللوحة (مقطع كيبل أو قيمة قاطع مختلفة).
- قاطع أكبر من سعة الكيبل، أو kA القاطع أقل من تيار القصر المتوقع.
- لوحات بدون Spare ways (أقل من 20%).
- غياب تفاصيل التأريض أو الـ SPD.
- كيبلات طويلة جداً بدون حساب هبوط جهد (Voltage drop).
